# Job Application Tracker 🚀

A simple web application to track job applications.

## Features
- Add job applications
- Search by company
- Delete jobs
- Dashboard (Total, Applied, Interview, Rejected)

## Tech Stack
- Python (Flask)
- SQLite
- HTML, CSS

## How to Run
1. Install Flask
   pip install flask

2. Run app
   python app.py

3. Open browser
   http://127.0.0.1:5000/
